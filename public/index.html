CloudSH 云 SSH 中继

点击命令复制。无需设置服务器，自动注册。Click to copy. Auto-register, no config needed.

Server / 云中继

[Linux] curl -fsSL https://cloudsh.yxpil.com/sh/install-server-linux.sh | bash
[macOS] curl -fsSL https://cloudsh.yxpil.com/sh/install-server-macos.sh | bash
[Win] curl -fsSL https://cloudsh.yxpil.com/sh/install-server-windows.bat -o install.bat && install.bat
